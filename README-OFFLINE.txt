JYOTI VEDIC AI — OFFLINE WEBSITE PACKAGE

Windows: double-click START-JYOTI-WINDOWS.bat
macOS/Linux: run ./START-JYOTI-MAC-LINUX.sh
Or run: python3 start.py

Requires Python 3.8+. The launcher starts a local-only server on this device
and opens http://127.0.0.1:8787 (or the next free local port). Keep the
terminal window open; press Ctrl+C to stop it.

Chart and Panchanga calculations use the included WebAssembly engine on
this device. No Jyoti API/backend or cloud hosting is used.
Optional place search needs internet and sends the search text to OpenStreetMap.
For offline use, enter latitude and longitude manually.

Android users should install the separate APK. Opening index.html directly
from a ZIP/file manager is not supported by browser file:// restrictions.
